## 3. 演练中发现的 4 件事（都是真跑出来的）

### 3.1 回退不会删掉新版多出来的文件

回退到 v0.9 之后，**v1.0 新增的 `js/api-error.js` 仍然留在线上**（HTTP 200）：

```
[回退后] 遗留的新版文件 js/api-error.js 还在吗: HTTP 200
```

原因：`tcb hosting deploy` 是**覆盖上传**，不是"同步" —— 它只传本次目录里的文件，不删线上多余文件。
**无害**（v0.9 的 `index.html` 不引用它），但**不是"干净的回退"**。要干净得点名删：

```bash
tcb hosting delete js/api-error.js -e ross-d2gimwy406e0d6812
```

> 这也是**不能用 `--prune` 图省事**的原因：托管根目录里还有 `__auth/`、`cloud-admin/` 等系统文件，
> 在根路径上 `--prune` 会把它们当"多余文件"删掉。宁可多一步点名删。

### 3.2 测试域名对浏览器的首次直接导航会拦一次

演练中途想给线上页面截图时撞上的：直接访问首页，浏览器的**第一跳拿到的是 HTTP 404 + 「风险提醒」页**，
页面上一个「确定访问」按钮（带 3 秒倒计时）。点完之后才 200 出真页面。

实测机制：

| 请求特征 | 服务端返回 |
| -------- | ---------- |
| 直接导航（无 Referer、`Sec-Fetch-Site: none`，浏览器 UA） | **HTTP 404 + 风险提醒页** |
| 同源二次导航（带 Referer、`Sec-Fetch-Site: same-origin`） | **HTTP 200 + 真页面** |
| curl / Node fetch（不走浏览器那套请求头） | **HTTP 200 + 真页面** |

两个实操结论：

1. **给线上页面截图，必须先点掉这个拦截页**，否则拍到的是一张 404 拦截图（脚本 `_day26_tmp/capture.mjs` 已处理：等 4 秒 → 点 `#submitBtn`）。
2. **`release.mjs verify` 不受影响**（走 Node fetch），所以"逐字节一致"这个判据是准的；
   但**别用 verify 的结果去代表"浏览器能打开"** —— 那是两件事。

### 3.3 「上一版是哪一版」不能凭印象

线上托管文件的时间戳是 `2026-10-09 22:54`，而那天有 4 个提交。
实际做法是**把线上文件抓下来，跟每个候选提交构建出的产物做差异比对**，才确定是 `87a897c`。

排查中还踩到一个坑：用 `git archive` 导出的工作树带 CRLF（`.gitattributes` 起作用了），
与线上 LF 字节直接 `diff -rq` 会**全文件报差异**；加 `--strip-trailing-cr` 后差异归零。
→ **比对前先统一行尾，否则会得出"哪个提交都不匹配"的错误结论。**

### 3.4 `verify` 报 MISSING 不等于失败

回退后若拿 v1.0 的清单去校验线上，`js/api-error.js` 会报 `MISSING`。
**这是预期现象**（v0.9 本来就没这个文件）。
判断"回退成功"要看的是：**目标版本自己的清单里，文件是否全部一致**。

## 6. 今日学习问题

> **回滚演练花了多久？真出事你敢不敢用这套流程？**

**花了 45 秒**（机器部分）；算上人眼核对与截图取证，整场 13 分 57 秒。

**敢用**，理由有三条，都是这次真跑出来的：

1. **它没有副作用。** 静态托管回退不动代码、不碰数据库、不重启函数 —— 最坏结果是"回到 45 秒前"。
   §3 里那三个发现（残留文件、拦截页、CRLF）没有一个是"回退会弄坏东西"，全是"回退后要多看一眼"。
2. **它可验证。** `verify` 把"到底退回去没有"从"我觉得页面看着像旧版"变成 **29 个文件的 sha256 逐字节比**，
   而且能一眼看穿 CDN 缓存骗人（§2 第 3 步）。
3. **它有前置条件，而且前置条件很短。** 就一条：**上线前存上一版产物**（`release.mjs snapshot`，一次命令）。
   这条满足，回退就是 45 秒；不满足，就只能走手册 §2.3 的抢救路径（导出 + 构建 + 上传，慢且依赖当时能构建成功）。

**唯一不敢直接用的地方**：云函数那层。现在 5 个函数都没有已发布版本，真出事只能"回灌旧代码"，
比静态托管麻烦得多。**建议下次发布顺手 `tcb fn publish-version`，把秒级切流量的后路留出来**（等零拍板）。
