### 2.1 ⚠️ CLI 与控制台口径不一致：CLI 漏报 PostgreSQL 整个模块（10-16 发现）

同一周期、同一环境，两个口径差 **367 点**：

| 口径 | 本期已用 | 说明 |
| ---- | -------- | ---- |
| 控制台「套餐用量」页 | **385.35 / 3000 点（12.8%）** | **权威**：PG 307.14 + 环境调用 13.44 + 云函数 4.71 + 静态托管 0.05 + 云存储 0.01 = **325.35**，**余 60.00 点未定位** |
| `tcb env usage` | **18.21 / 3000 点（0.61%）** | API calls 11.9 + 云函数 4.71 + HTTP 网关 1.54 + 静态托管 0.05 + 存储 0.01 |

**怎么确认是「漏报」而不是「口径不同」**：两边的**云函数**完全对得上 ——
CLI：`MemoryUse 25 GBs = 3.33 点` + `Outflow 1806 KB = 1.38 点` → **4.71 点**；
控制台：云函数 **4.71 点**，且写着「资源使用量 25 GBs / 外网出流量 1.76 MB」（1806 KB ≈ 1.76 MB）。
同源同值 → 是**同一套计量**，只是 CLI 这份返回里 **PG 相关的 `CreditsValue` 全是 0**。

**又两条同源证据**（10-16 补齐截图后逐项对上）：

| 控制台 | `tcb env usage` | 对不对得上 |
| ------ | --------------- | ---------- |
| 环境调用 **13.44 点**（云开发 API 1190 次 + HTTP 517 次） | `API calls 11.9`（1190 次）+ `HTTP gateway 1.54`（517 次） | ✅ **连次数都逐一吻合** |
| 静态托管 **0.05 点**（容量 17 MB·天） | `HOSTING Capacity 17 MB → 0.05` | ✅ |
| 云存储 **0.01 点**（调用 5 次） | `COS WriteRequests 5 次 → 0.01` | ✅ |

→ 五个可见模块**全部对得上，唯独 PostgreSQL 在 CLI 里整块消失**。这就是结论：**CLI 漏项，不是口径不同**。

**原始返回佐证**（`tcb env usage --json`）：13 条 `Usages` 里非零的只有 6 项；
`ResourceType` 全集含 `FLEXDB` / `TDSQL`，但它们的 `CreditsValue` 全为 `0`；
把 43 条 `MetricUsageDetail` 的 `CreditsValue` 加总，恰好 **18.21** —— **没有 PostgreSQL 那一条**。

**写成规矩**：**看额度以控制台为准**。`tcb env usage` 适合看「网关 / 函数 / 托管」的分项与趋势，
**不能拿它的合计当本期总消耗**（会低报约 95%）。

**PG 是真正的消耗大户**：307.14 点 ÷ 1.06 CU·时 ≈ **290 点每 CU·时**（推算）。
换句人话：**CU 使用量累积到 ~10 CU·时，3000 点就没了**。
本周期过了 13 天用掉 1.06 CU·时，线性外推整期约 2.5 CU·时 ≈ 730 点（≈ 24%，仍安全）——
但**这是整份用量表里唯一需要每月盯一眼的数**（见 §4.3）。

**读法**：

- 用量**统计有延迟**（官方说明不超过 2 天），所以「今天刚跑的一批请求」不会立刻出现在表里；
- 免费体验版**不支持资源包、也不支持按量付费** —— 额度用完就是停，不会自动扣费；
- 按当前节奏（一天 1 次部署 + 少量接口调用），一个月 1,000 点都用不到，**额度不是本项目的风险点**。

| ③ 控制台 | 云开发控制台 → 数据库 → 导出 | 习惯用可视化的人 | PostgreSQL 环境的导出入口与 MySQL 不同，且同样要扫码登录 |

脚本的几条设计点（都不是随便定的）：

- **走 PostgREST**（和云函数同一条 HTTP 路），因为体验版**不支持 PG 的 TCP 直连**；
- **零依赖**，只用 Node 原生模块，和 `shared/pg.js` 一个路子；
- **行数自校验**：先用 `Prefer: count=exact` 向库要整表总数，再分页拉，最后比对 —— `rows.length === total` 才算成功。**只要有一张表对不上，退出码就是 1，并且明说「这次导出不可信」**（Day 21 的教训：比对脚本不打印「比了多少条」，就会输出「0==0==0 完全一致」的假结论）；
- **密钥只读不打印**：从 `.env` 或环境变量读，终端只输出「有 / 长度」，**不输出值**；
- 输出目录 `db/exports/` **已加进 `.gitignore`**（一次约 1.4MB，且是一次性快照，不该进仓库）。
