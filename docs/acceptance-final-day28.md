## 三、演示提纲（3–5 分钟）

### 0:00–0:30 ① 用户问题

- **谁**：每天想看体育、但不愿意装三个 app 的人。
- **痛点**：虎扑 / 腾讯体育 / 央视体育各是一摊，赛程比分又散在别处；同一条新闻三个平台都推。想「一页看完」就得来回切。
- **产品一句话**：《每日体坛速览》——打开就是一个页面：**三平台热搜聚合 + 今日速览 + 赛程比分 + 联赛板块**，不用注册，点开即看。
- 开场口令：「先看首页——三块榜单是真实抓取的三平台热榜，标题旁的『最近更新』是抓取时间，不是写死的。」

### 0:30–2:00 ② 核心流程（当场走一遍）

| 步 | 走哪里 | 看什么 |
| - | ---- | ---- |
| 1 | 首页 | 三块榜单 + 「最近更新」时间戳 |
| 2 | 点任一条 → 详情页 | 「收藏这条」→ **真的写进数据库**（当场点，当场出 id） |
| 3 | 速览页 | 标签筛选（渐变高亮、防连点） |
| 4 | 赛程页 | 搜索框 + 6 个联赛筛选 |
| 5 | `league.html?lg=nba` | Tab（赛程/排行/晋级图/球员）由数据文件驱动 |
| 6 | 收口：接口检查台 `checkup.html` | health 状态 + 两张核心表真实数据 + **当场点一次写入测试并读回** |

- 数据链路一句话：**浏览器 → CloudBase 网关 → HTTP 云函数 → PostgreSQL**，前后端契约在 `api-contract.md`。

### 2:00–3:00 ③ 提示词改写（AI 从「许愿」到「派活」）

| 阶段 | 提示词 | 为什么改 |
| - | ---- | ---- |
| 反例 | 「帮我做个体育资讯网站」 | 产出结构随机，无法验收 |
| 改写 1 | **先立契约再写码**：先产出 `api-contract.md`（路径/方法/字段名/状态码/包络），一切实现以契约为准 | 接口形状才能被逐字段验证（23/23） |
| 改写 2 | **把环境约束写进提示词**：云函数零依赖、用 Node 原生 https 走 PostgREST，不拼 SQL | 原方案实测跑不通（体验版无 PG TCP 直连、HTTP 云函数不能装依赖） |
| 改写 3 | **加可判定的验收条件**：「四态齐备」「字段 camelCase」「缺字段一次列全+中文提示」 | 每条都能当场判真假，消灭「基本完成」 |
| 改写 4 | **把「验证」也交出去**：让 AI 写回归脚本和形状比对，改完必须跑绿 | 18 条分支用例 + 23 项断言，重构才敢说「行为不变」 |
| 改写 5（第 4 周） | **把踩过的坑固化成门禁**：Day 25 把真实踩坑写成 25 项检查（PASS/FAIL/SKIP + 证据），并放一个「故意做坏的样本项目」自证不虚报 | 发布前自检从「凭感觉」变成「跑一遍」 |

### 3:00–4:00 ④ 验证方式（每层给数字）

| 层 | 做法 | 数字 |
| - | ---- | ---- |
| ① 本地回归 | `test-api-local.cjs --with-db` | 18/18（含 400/404/405/500 分支） |
| ② 契约形状比对 | 逐字段对 `api-contract.md` | 23/23 |
| ③ 公网 + 真库 | 今天当场：POST→读回→PATCH→软删→查不到 | 全 200，`verifiedGone:true` |
| ④ 发布门禁 | Day 25 verify-project | 25 项逐条 PASS/FAIL + 坏样本自测 |
| ⑤ 回滚演练 | Day 26 退 v0.9→恢复 v1.0 | 全程 13 分 57 秒，机器 45 秒 |
| ⑥ 真人试用 | Day 27 第三方 12 步脚本 | 唯一 P1 已修（导航加检查台入口） |

### 4:00–4:40 ⑤ 平台限制（讲清楚「哪些是平台给的边界」）

- **体验版不支持 PostgreSQL TCP 直连** → 云函数走 PostgREST HTTP，查询条件走参数不拼 SQL；
- **HTTP 云函数不能云端装依赖** → 全部零依赖（Node 原生模块），shared/ 必须组装成自包含目录再部署；
- **静态托管没有版本管理** → 自造「产物快照 + sha256 账本 + 发布/回滚脚本」补上（Day 26）；
- **`tcb db backup` 只支持 MySQL**，本项目是 PG → 自造导出脚本（行数对不上就报不可信）；
- **测试域名首次访问有「风险提醒」拦截页**（Day 27 有截图证据）；自定义域名需备案，未做；
- 托管 `--prune` 会连 `__auth/`、`cloud-admin/` 系统文件一起删 → 只能点名删。

### 4:40–5:00 ⑥ 后续优化计划

1. 热搜同步做成 CloudBase 定时触发器（消灭手动三步）；
2. 写接口加鉴权（现在公开 + 字段校验兜底，契约里已如实登记）；
3. 补 `GET /api/leagues/:id`，联赛页从静态 JSON 切接口，ucl/epl 换真数据；
4. 演练一次 L2 `config-route` 切流量；给 PG 找备份/恢复方案；
5. 自定义域名（去风险提醒页）+ `digest.html` 去留拍板。
